# AraToons Kodi Repository

Kodi addon repository for Arabic streaming content.

## Installation

### Method 1: Install from ZIP URL (Recommended)

1. Open Kodi and go to **Add-ons**
2. Click the **Open Box icon** (Install)
3. Select **Install from zip file**
4. Enter: `https://raw.githubusercontent.com/aionoid/repository.aratoons/main/zips/repository.repository.aratoons/repository.repository.aratoons-1.0.2.zip`
5. Wait for the "Repository enabled" notification
6. Go to **Add-ons** > **Install from repository** > **AraToons Repository**
7. Select **AraToons** and click **Install**

### Method 2: Install using Kodi's File Manager

1. Go to **Settings** > **File Manager** > **Add source**
2. Enter: `https://aionoid.github.io/repository.aratoons/`
3. Name it "AraToons"
4. Go to **Add-ons** > **Open Box icon** > **Install from zip file**
5. Select **AraToons** source > find **repository.repository.aratoons-1.0.2.zip**
6. Wait for the notification, then go to **Install from repository** > **AraToons Repository**
7. Select **AraToons** and click **Install**

## How to update the repository

After modifying addon source folders:

```bash
cd ~/Documents/git/repository.aratoons
python3 generator.py
git add -A
git commit -m "📦 chore: update repository"
git push
```

The `generator.py` script scans all folders containing `addon.xml`, creates ZIP packages in `zips/`, and generates `addons.xml` + `addons.xml.md5`.

## Structure

```
repository.aratoons/
  repository.aratoons/              # Repository addon source (addon.xml + icon.png)
  plugin.video.stardima/            # Addon source code
  repository.repository.aratoons-1.0.2.zip  # Repo ZIP at root (for Kodi File Manager)
  zips/                             # Built artifacts (generated by generator.py)
    addons.xml                      # Master index
    addons.xml.md5                  # MD5 checksum
    plugin.video.stardima/
      plugin.video.stardima-1.5.6.zip
    repository.repository.aratoons/
      repository.repository.aratoons-1.0.2.zip
  generator.py                      # Generates zips + addons.xml from source folders
  index.html                        # Landing page with installation instructions
  .gitignore
  README.md
```
