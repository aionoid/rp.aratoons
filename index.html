Method 1 — Install from ZIP URL

Fastest way — no extra steps needed

  1. Open Kodi and go to Add-ons
  2. Click the Open Box icon (top left) → Install from zip file
  3. Enter this URL:
https://raw.githubusercontent.com/aionoid/rp.aratoons/main/zips/repository.repository.aratoons/repository.repository.aratoons-1.0.2.zip
  1. Wait for the “Repository enabled” notification
  2. Go to Add-ons→ Install from repository→ AraToons Repository
  3. Select AraToons and click Install

Method 2 — Install using File Manager

Add our GitHub Pages as a source, then browse for the ZIP

  1. Go to Settings→ File Manager→ Add source
  2. Enter this URL:
https://aionoid.github.io/rp.aratoons/
  1. Name it “AraToons”
  2. Go to Add-ons→ Open Box icon→ Install from zip file
  3. Select AraToons source → find repository.repository.aratoons-1.0.2.zip
  4. Wait for the notification, then go to Install from repository→ AraToons Repository
  5. Select AraToons and click Install
